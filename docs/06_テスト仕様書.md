## 1. API（backend/tests）

### 認証・ユーザー（test_auth.py）

| ID | 確認すること |
| --- | --- |
| A01 | ログイン → 自分の情報 → ログアウトで 401。DB には Cookie の値ではなく 64 文字のハッシュだけ |
| A02 | Cookie に HttpOnly・SameSite=Lax・Path=/ |
| A03 | パスワード違いと存在しないメールで同じメッセージ（いるかどうかを知られない） |
| A04 | 5 回失敗でロック（正しいパスワードでも不可）、ロックが切れたら入れる、失敗が操作履歴に残る |
| A05 | メールアドレスの大文字小文字・前後の空白を区別しない |
| A06 | 使用停止にすると、ログイン中の人も切れて、ログインもできない |
| A07 | CSRF のヘッダーがない書き換え（ログインも）は 403、読むだけなら不要 |
| A08 | ログインしていないと各 API は 401 |
| A09 | マネージャー・メンバーはユーザー管理の API を使えない（403） |
| A10 | パスワードの決まり（短い・英字だけ）、返事にパスワードやハッシュが入らない、メールの重複（大文字違い）は 409、追加した人でログインできる |
| A11 | 最後の管理者は外せない |
| A12 | パスワード変更：今のパスワードが必要、変えた端末は使えて、ほかの端末は切れる |
| A13 | 知らない項目（`role` など）は 422 |
