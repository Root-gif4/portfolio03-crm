# 01 要件定義書

## 1. 背景と目的

小さな営業チーム（数人〜20 人程度）では、顧客の情報は Excel、商談の進み具合はチャット、やることは各自のメモ、と散らばりがちで、
「だれが・どの案件を・いつまでに」が見えにくい。本システムは顧客・案件・タスクを一か所にまとめ、
期限切れや締める予定の案件をすぐ分かるようにする。あわせて、だれが何を変えたかを記録し、権限で変更できる人を絞る。

## 2. 利用者

| 役割 | 人 | 主な使い方 |
| --- | --- | --- |
| 管理者 | 事務・システム担当 | ユーザーの追加と権限の設定、すべての操作 |
| マネージャー | 営業の責任者 | チーム全体の案件・タスクの管理、削除、操作履歴の確認 |
| メンバー | 営業担当 | 自分の顧客・案件・タスクの登録と更新、全体の閲覧 |

## 3. 機能要件

| No | 機能 | 内容 |
| --- | --- | --- |
| F1 | ログイン・ログアウト | メールアドレスとパスワード。続けて 5 回失敗すると 15 分ロック。ログイン状態は 12 時間 |
| F2 | ユーザー管理 | 追加・名前と権限の変更・使用停止・パスワード再設定（管理者だけ）。最後の管理者は外せない |
| F3 | 権限管理 | 管理者・マネージャー・メンバーの 3 段階。メンバーは担当のデータだけ変更できる |
| F4 | 顧客管理 | 会社名・フリガナ・業種・電話・メール・住所・メモ・担当者。案件のある顧客は削除できない |
| F5 | 案件管理 | 顧客・案件名・ステータス・見込み金額・開始日・受注予定日・内容・担当者。一覧とボード表示。受注予定日は開始日より前にできない |
| F6 | タスク管理 | 案件・やること・状態・優先度・開始日・期限・担当者・メモ。「完了にする」ボタンで完了、「元に戻す」で戻せる。期限は開始日より前にできない |
| F7 | ステータス管理 | 案件は 見込み／提案中／交渉中／受注／失注。受注・失注で閉じた日を記録し、戻すのはマネージャー以上。タスクは 未着手／対応中／完了 |
| F8 | ダッシュボード | 顧客数、進行中の案件数、見込み金額、今月の受注金額と受注率、期限切れのタスク数（マネージャー以上はチーム全体、メンバーは自分の担当）、ステータス別金額、月別受注金額（6 か月）、自分のタスク、30 日以内に締める案件、最近の動き。進行中の案件・見込み金額・期限切れのカードは押すと一覧が開く（押せるカードは枠と矢印で見分けられる） |
| F9 | 検索・絞り込み | 文字の部分一致、ステータス・担当者・業種・期限・金額で絞り込み、並び替え、ページ送り |
| F11 | 予定表 | 案件（開始日 → 受注予定日）とタスク（開始日 → 期限）を帯で並べるガントチャート。1 か月／3 か月、前後の移動、担当者・受注失注・タスクの表示の切り替え。今日の線 |
| F12 | 期限のお知らせ | ログインしたとき、自分が担当で期限切れ・期限が近い（1〜7 日前から、既定 3 日）タスクをダイアログと音で知らせる。日数・音のあり／なしは設定で変えられる |
| F13 | 進み具合の報告 | 担当者がタスクの進み具合（0〜100%）・見通し（予定どおり／遅れそう）・ひとこと（200 文字）を報告する。報告は操作履歴に残る。完了で 100%、未着手は 0%、報告すると未着手は対応中になる |
| F14 | 期限前の見通しの確認 | 期限のお知らせの各タスクに「予定どおり」「遅れそう」のボタン。押すと見通しとして報告される |
| F15 | チームの状況 | 管理者・マネージャーだけ。メンバーごとの未完了・対応中・期限切れ・7 日以内・遅れそう・止まっている（7 日以上報告も変更もない）の数、平均の進み具合、最後の報告。遅れそう・期限切れ・止まっているタスクの一覧。数字を押すと絞り込んだタスクの一覧へ |
| F10 | 操作履歴 | 追加・変更・削除・ログイン・ログアウト・ログイン失敗・パスワード変更を記録。変わった項目の前と後。マネージャー以上が見られる |

## 4. 非機能要件

| 項目 | 内容 |
| --- | --- |
| 使いやすさ | 画面・メッセージはすべて日本語。入力の誤りは項目の下に出す。ライト／ダーク、スマホ幅でも使える |
| 正しさ | 同時に変更したとき、あとから保存した人が先の変更を消さない（楽観的ロック） |
| 安全性 | パスワードはハッシュで保存。セッションの Cookie は JavaScript から読めない。CSRF・XSS・SQL インジェクション対策。権限は API 側で判定 |
| 性能 | 目標：顧客 1 万・案件 3 万件程度で一覧が 1 秒以内（ページ送り・インデックスで対応。大量データでの計測はまだ） |
| 保守性 | 画面と API を分ける。権限・入力チェックは 1 か所。マイグレーションでテーブルを管理。自動テスト |
| 監査 | 操作履歴は追加だけ（変更・削除の API がない） |
| 費用 | 無料のソフトだけ（ローカルで動かす） |

## 5. 対象外（今回は作らない）

- ほかの PC・インターネットへの公開（HTTPS・本番サーバー）
- メール通知、ファイル添付、見積書の作成、外部サービスとの連携
- 2 段階認証、パスワードを忘れたときのメール再設定（管理者が再設定する）
